# Inferencia estadística

Cómo se aprende de una muestra lo que no se ve de la población: distribuciones muestrales, máxima verosimilitud, suficiencia, Cramér-Rao, intervalos de confianza, el lema de Neyman-Pearson, la razón de verosimilitudes, pruebas no paramétricas y remuestreo, con las demostraciones completas.

**Ver en línea:** https://aaramirez.github.io/mate-inferencia/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
